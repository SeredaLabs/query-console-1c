## Evidence and method

- SmartLogistic DEV MCP `validate_query`, 2026-10-21. No query execution or
  database values were requested. Build **8.3.15.1489**, confirmed by the user;
  the MCP response does not expose the build.
- [Recorded cases](../../../test/fixtures/platform/v5-phase5-8.3.15.json)
  contain exact adapted inputs, platform errors/canonical texts, measured local
  outcomes and hashes of generated texts independently revalidated on the platform.
  Parameter-type lists were omitted; no business data is stored.
- The 34-area / 96-form [queue](../../../test/fixtures/grammar-parity/probe-queue.jsonl)
  was split into independent statements and individual function probes so one
  failure cannot hide the remaining forms. The English temp-table batch stays intact.
- Reserved alias `В` caused early failures in the queue. Those discovery failures
  are not grammar verdicts: affected cases were rerun with `Вал`. Change-table
  alias `И` was replaced with `Изм`. Live object/field substitutions are recorded.
- Each local input ran in a separate Node child process with a 10-second timeout:
  `tryOpenDesignerBatch` → `generateBatch` → reopen → `decideApply`, including
  `findUnsafeVirtualTables` and `findMalformedCustomExpressions` blockers.
  Constructor canonical text was measured separately. No timeout or exception.
- Two modes: no resolver, and the committed BSP corpus resolver. The latter is
  **not** metadata for this live database. Four source probes are rejected only
  with that resolver because their objects are absent; this is not a parser gap
  or proof of behavior with matching live metadata.

29 platform-refused inputs still allow local Apply: 25 version-qualified syntax
cases (index sets, grouping sets, string/math functions, unique identifier), the
scalar subquery, and three missing-table cases. **Do not turn these into 29
universal grammar defects.** This build predates the reference checklist; missing
metadata also does not establish invalid grammar. No target-version gate is
claimed or introduced by this audit.

## Remaining work

1. Reprobe newer syntax on a supported modern platform, recording its exact build.
   Refusal on 8.3.15 does not establish universal invalidity or first supported version.
2. Supply external data sources, calculation registers/charts and sequences.
   The latter types return empty metadata lists; the connector cannot enumerate
   external sources, so their absence is not proven. No probes were run for
   `source.external-data-source`, `virtual-table.calculation`, or
   `virtual-table.sequence-boundaries`.
3. Finish partially available source/change-table forms. Missing route-point and
   change tables are not negative grammar evidence; exchange-plan participation
   was not independently proven. Constants, sequences and recalculation change
   tables are still untested.
4. Repair and run a complete characteristics probe, both braced and unbraced,
   before making a scope decision. Extend periods/periodicity and English-keyword
   probes where the broad question exceeds the examples: touching one form ID
   does not prove every parameter or keyword variation.
5. Review promotion of independent cases into catalog/forms and reduce the queue
   only when each area's requirements are satisfied. Existing G2/G3/G5 stay
   unchanged; C37–C40 are documented separately rather than hidden by updated goldens.

V5 remains OPEN · P1. This run establishes useful partial evidence, not completion
of all 96 forms or the Query Core v1 gate.
