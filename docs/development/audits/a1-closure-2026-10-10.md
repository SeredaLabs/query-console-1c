## Ownership decision

Identical regexes in several modules are still competing classifiers. The
identifier alphabet now has one owner, the lexer:

- `isNameToken(token)`: ident or keyword, not the `#…` form;
- `isIdentifierName(text)`: the whole text is exactly one name token.

Consumers read lexer facts instead of character classes:
`exprAutoAlias.bareParamName` (a single `param` token whose name is an
identifier; used by parser, generator and union columns) and
`representationAutoAlias` (a token walk). The UNION alias checks in Classic
`UnionsTab` and Canvas `UnionMappingPopover` call `isIdentifierName`.
No new tokenization layer was added.

`inferUndefinedTempTables` (reproduced with a resolver, before and after
`9678046`): `ВЫБРАТЬ Т.Ціна КАК Х ИЗ ВТ КАК Т; ВЫБРАТЬ Т.* ИЗ ВТ КАК Т` infers a
column `Ц`, and the star prints `Т.Ц КАК Ц` (`Т.Gültig` → `G`). It is the same
raw scanner as R5. A token scan fixes both, so the A1 slice and R5 must be
planned together.

`parseStar` cannot move first. With a resolver, a star over a source without
resolvable columns already drops the statement on `9731382`
(`ВЫБРАТЬ Га.* ИЗ ВТ КАК Га` → empty text; recorded under C24 as a core defect
not reproduced through the Designer on `0ce22b9`, and a C24 prerequisite). Migrating
`parseStar` alone gave `Ґа.Код …; Ґа.*` the same path and dropped the statement,
because inference cannot read `Ґа.Код` yet. The change was reverted. Order:
inference first, then `parseStar`.

## Verification of `9678046`

- E2E: Classic and Canvas accept `Ціна`/`Gültig` as UNION aliases and still
  reject `1Ціна`; both fail on `9731382`.
- Differential vs `9731382`: 2409 cases (corpus 1976, oracle 181, payload
  matrix 252 over 9 names × 14 contexts, with/without resolver): 56 changed,
  all non-`А-Я` names, each byte-equal to the `Цена` output with the name
  swapped; corpus/oracle 0; no new instability or errors.
- Typecheck; unit 5845 passed + 5 skipped (incl. C25 literal suites); e2e 174;
  `docs:check`; `diff --check`.

Pre-existing, also for Cyrillic, not changed: `ВЫБРАТЬ &Цена, &Цена` is
platform-valid (columns `Цена`, `Цена1`; canonical text `… КАК Цена, … КАК Цена1`),
but the generator prints two `КАК Цена`, which the platform rejects
(`Duplicate alias`). The Designer refuses to open such text
(`Повторяющийся псевдоним`), so Apply never writes it. A platform-valid query
is refused: grammar parity (V5), not A1.

`ПРЕДСТАВЛЕНИЕ(Т . А)`: whitespace around the path dot is a platform syntax
error. `9678046` changed only the auto alias of this already invalid input
(`Поле1` → `АПредставление`). Accepting it, and normalizing `Т . А` to `Т.А`,
predates A1 and is a grammar-parity question (platform-invalid input accepted),
not an A1 ownership blocker.

## Addendum 2026-10-11: closure

Branch `refactor/a1-6-lexical-gates`, on top of `35937c3`. Each step has a
regression that fails on its parent, a differential with 0 unexplained cases,
corpus 7904/7904 unchanged (0 ERR), typecheck, full unit, e2e 174, and C25 v3 /
ИТОГИ totals with counters identical to the baseline and 0 corruption.

1. **`7c71a10` A1-7 + R5.** `inferUndefinedTempTables` (also on the Designer
   path, which runs inference without metadata) reads references and stars
   from lexer tokens. `Т.Ціна` was inferred as `Т.Ц КАК Ц`; it now equals
   `Т.Цена`. Comments and literals (`// см. Т.Фантом`, `"Т.Строка"`, `"Т.*"`,
   `// *`) no longer create columns. Differential vs `35937c3`: 2016 cases,
   786 unchanged, 138 name parity, 1092 payload-neutral, 0 other. The platform
   oracle could not be used directly: the probe service compiles the query
   first and rejects `Т.*` over an undefined temp table (`Table not found`).
2. **`38663ca` C24 prerequisite (data loss).** Found while preparing
   `parseStar`: with any temp table in the batch, the Designer path removed a
   wildcard over a real table (`ВЫБРАТЬ 1 КАК А ПОМЕСТИТЬ ВТ; ВЫБРАТЬ Т.* ИЗ
   Справочник.Валюты КАК Т` lost its statement; Apply ok), because a
   temp-table-only resolver was treated as authoritative. Fixed narrowly;
   recorded under C24, which stays OPEN.
3. **`7ff2490` `parseStar`.** Each wildcard head segment is checked with
   `isIdentifierName`; `Ґа.*`, `Ціна.*`, `Gültig.*` now behave exactly like
   `Га.*`. Differential vs `38663ca`: 840 cases, 516 unchanged, 228 alias
   parity, 96 alias parity that also inherits a known reopen difference of
   the `Т` alias (an empty statement, as the platform makes it, leaves a
   trailing separator that collapses on the second pass), 0 other.

All seven exit criteria pass. Remaining work has owners outside A1: C24
(wildcard parity), C26, C2, V5 (duplicate alias numbering, whitespace around
the path dot), R4, R6–R8, R11, R12, N1, N3, N4.
