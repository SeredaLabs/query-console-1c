# Початок роботи

[English](../en/getting-started.md) · [Українська](../uk/getting-started.md) · [Русский](../ru/getting-started.md)

## Вимоги

- VS Code 1.90 або новіший.
- Файл `.bsl`.
- Для таблиць і полів конфігурації — файлове XML-вивантаження конфігурації 1С.

## Команди

| Команда | Призначення |
|---|---|
| **1C: Лише текст запиту** | Вставити або змінити рядок запиту |
| **1C: З кодом обробки результату** | Створити запит із BSL-обгорткою обробки результату |
| **1С: Перебудувати індекс метаданих** | Перебудувати похідні файли метаданих і кеш |

## Створення запиту

1. Відкрийте `.bsl` і поставте курсор у місце вставлення.
2. У контекстному меню редактора виберіть **1С: Конструктор запитів**.
3. Виберіть **Лише текст запиту** або **З кодом обробки результату**.
4. Додайте таблиці й поля, налаштуйте запит і натисніть **ОК**.

Перша команда вставляє BSL-рядок із SDBL. Друга вставляє згенеровану BSL-обгортку
для обробки результату. Жодна команда не виконує запит.

## Відкриття наявного запиту

Поставте курсор усередину підтримуваного статичного BSL-рядка та виконайте одну
з команд. Після **ОК** конструктор замінить той самий діапазон. **Скасувати** не
змінює редактор.

## Наступні кроки

Налаштуйте [метадані](metadata.md), ознайомтеся з [конструктором](query-designer.md)
і перегляньте [обмеження](limitations.md) до редагування складних ручних запитів.
