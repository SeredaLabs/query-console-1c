# Усунення проблем

[English](../en/troubleshooting.md) · [Українська](../uk/troubleshooting.md) · [Русский](../ru/troubleshooting.md)

## Команда відсутня

Контекстне підменю показується лише для `.bsl`. Команду **1С: Розібрати
метадані в YAML** шукайте в палітрі команд. Перевірте, що розширення ввімкнено, а версія
VS Code — 1.90 або новіша.

## Запит не виявлено

Поставте курсор усередину статичного BSL-рядка. SDBL має починатися з `ВЫБРАТЬ`
або `УНИЧТОЖИТЬ` після коментарів і пробілів. Динамічна конкатенація не
підтримується.

## Немає таблиць або полів

Перевірте `queryConsole.metadataPath` і наявність `Configuration.xml`, а потім
виконайте **1С: Розібрати метадані в YAML**. Застарілий кеш не оновлюється автоматично.

## Не застосовуються зміни тексту

Ручну зміну неможливо подати поточною моделлю. Спростіть копію до підтримуваної
конструкції або скасуйте операцію, щоб зберегти попередню модель.

## Як повідомити про відтворювану проблему

Додайте версії VS Code і розширення, ОС, налаштування, найменший безпечний запит
і точні кроки. Не публікуйте конфіденційне вивантаження конфігурації.
