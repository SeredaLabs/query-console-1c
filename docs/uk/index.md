🧩 **1C: Query Constructor** — візуальний редактор статичних запитів 1С SDBL у
BSL-файлах, а також семантичний шар — підказки, автодоповнення та
діагностика — що працює прямо в тексті запиту без відкриття конструктора. Він
генерує код, але не є консоллю, підключеною до бази 1С.

## 🌍 Мова

Команди, налаштування, сповіщення та WebView використовують мову VS Code для
англійської, української й російської. Для інших мов використовується англійська.
Назви об’єктів метаданих і синтаксис SDBL не перекладаються.
