🧩 **1C: Query Constructor** — визуальный редактор статических запросов 1С SDBL в
BSL-файлах, а также семантический слой — подсказки, автодополнение и
диагностика — работающий прямо в тексте запроса без открытия конструктора. Он
генерирует код, но не является консолью, подключённой к базе 1С.

## 🌍 Язык

Команды, настройки, уведомления и WebView используют язык VS Code для
английского, украинского и русского. Для остальных языков используется
английский. Имена объектов метаданных и синтаксис SDBL не переводятся.
