# 🚀 Начало работы

[English](../en/getting-started.md) · [Українська](../uk/getting-started.md) · [Русский](../ru/getting-started.md)

## ✅ Требования

- VS Code 1.90 или новее.
- Файл `.bsl`.
- Для таблиц и полей конфигурации — файловая XML-выгрузка конфигурации 1С.

## ⌨️ Команды

| Команда | Назначение |
|---|---|
| **1C: Только текст запроса** | Вставить или изменить строку запроса |
| **1C: С кодом обработки результата** | Создать запрос с BSL-обёрткой обработки результата |
| **1С: Перестроить индекс метаданных** | Перестроить производные файлы метаданных и кеш |

## 🛠️ Создание запроса

1. Откройте `.bsl` и поместите курсор в место вставки.
2. В контекстном меню редактора выберите **1С: Конструктор запросов**.
3. Выберите **Только текст запроса** или **С кодом обработки результата**.
4. Добавьте таблицы и поля, настройте запрос и нажмите **ОК**.

Первая команда вставляет BSL-строку с SDBL. Вторая вставляет сгенерированную
BSL-обёртку для обработки результата.

> ⚠️ **Важно:** Ни одна команда не выполняет запрос — обе только генерируют
> BSL-код.

## 📂 Открытие существующего запроса

Поместите курсор внутрь поддерживаемой статической BSL-строки и выполните одну из
команд. После **ОК** конструктор заменит тот же диапазон. **Отмена** не изменяет
редактор.
