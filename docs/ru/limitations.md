# ⚠️ Ограничения

[English](../en/limitations.md) · [Українська](../uk/limitations.md) · [Русский](../ru/limitations.md)

## 🚫 Расширение не выполняет запросы

Обе команды генерируют BSL-код. Вариант с обработкой результата создаёт код для
последующего выполнения в 1С; расширение не имеет подключения к базе, таблицы
результатов, истории выполнения или транспорта запросов.

## 🧪 Обнаружение и проверка имеют границы

Поддерживаются статические строки с `ВЫБРАТЬ` или `УНИЧТОЖИТЬ`. Толерантный
парсер и валидатор не являются полным компилятором 1С. Успешный разбор не
гарантирует корректность каждого ручного выражения, поля, цепочки через точку
или платформенной конструкции.

## ⛔ Исключения из обратного преобразования

> Не применяйте изменения для этих виртуальных таблиц с тремя или более
> позиционными параметрами:

- `РегистрРасчета.*.ДанныеГрафика`
- `РегистрРасчета.*.ФактическийПериодДействия`
- `Последовательность.*.Границы`

Общий резервный алгоритм не гарантирует восстановление. Параметры
`Субконто(...)` регистров бухгалтерии поддерживаются и покрыты тестами.

## 🗂️ Границы метаданных

Кеш не сравнивается с XML автоматически. Поиск имеет ограниченную глубину, а
неподдерживаемые типы метаданных не попадают в дерево. Обновляйте кеш вручную.
