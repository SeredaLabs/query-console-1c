# 📘 User guide

[English](../en/index.md) · [Українська](../uk/index.md) · [Русский](../ru/index.md)

🧩 **1C: Query Constructor** is a visual editor for static 1C SDBL queries embedded in
BSL source files. It generates code; it is not a query console connected to a 1C
database.

## 🌍 Language

Commands, settings, extension-host notifications, and the WebView follow the VS
Code display language for English, Ukrainian, and Russian. Other locales use
English. Metadata object names and SDBL syntax are never translated.
