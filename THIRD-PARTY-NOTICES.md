# Уведомления о стороннем ПО

Этот проект использует сторонние активы, распространяемые на условиях их
собственных лицензий.

## @vscode/codicons

Иконки тулбара и шевроны дерева — набор `@vscode/codicons`.

- Источник: https://github.com/microsoft/vscode-codicons
- Иконки: Creative Commons Attribution 4.0 International (CC-BY-4.0), © Microsoft Corporation.
- Код: MIT License, © Microsoft Corporation.

## Иконки видов метаданных

Контуры иконок для видов метаданных (Справочник, Документ, Регистры,
Планы и т.д. — см. `src/webview/components/metadataKindIcons.ts`)
позаимствованы из расширения VS Code `zerobig/vscode-1c-metadata-viewer`,
чтобы дерево метаданных выглядело так же, как в других 1С-расширениях.

- Источник: https://github.com/zerobig/vscode-1c-metadata-viewer
- Лицензия: MIT License, Copyright © 2015 Ilya Bushin.
- Изменение: цвет залития перекрашен в `currentColor` (было двумя фиксированными
  цветами под тёмную/светлую тему по отдельности), чтобы иконка следовала теме
  редактора так же, как остальной интерфейс.
